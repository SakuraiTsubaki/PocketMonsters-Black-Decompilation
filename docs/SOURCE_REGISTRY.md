# Public Source Registry — Pokémon Generation V

## Purpose

This file is the authoritative census of **publicly accessible source material** used to reconstruct and document Pokémon Black, White, Black 2, and White 2 when no local retail ROM is available.

The survey baseline is the original Japanese release of each game, but every official regional/language/revision build remains a first-class target.

A source category is **not complete** merely because one useful page or tool was found. Completion requires enumerating the relevant child pages, files, repositories, archives, releases, historical captures, or records and recording their coverage.

## Enumeration states

- **Registered** — source root identified; useful material confirmed.
- **Enumerating** — child pages/files/records are being listed and classified.
- **Enumerated** — the relevant public collection has been itemized to the practical limit of the source.
- **Archived/partial** — only preservation copies or partial surviving material are available.
- **Blocked** — source exists but automated access is restricted; use search indexes, mirrors, archived captures, or manual references without inventing content.
- **Candidate** — likely relevant source class not yet verified.

## Evidence roles

- **Official primary** — Nintendo, The Pokémon Company, Pokémon Korea, official manuals, service notices, official game/event/service pages.
- **Preservation** — archived downloadable content, event files, historical web captures, catalog records, scans, prototype/prerelease preservation.
- **Direct technical** — source code or documentation implementing file formats, save structures, script formats, graphics, audio, maps, or executable behavior.
- **Reverse engineering** — published ROM/save research, NARC maps, offsets, structures, behavior tests, disassembly notes.
- **Secondary reference** — maintained databases/wikis used for discovery and cross-checking; technical claims require stronger evidence.

### 10. Catalog / dump identity / revision preservation

This category must identify every known retail build, serial/product code, revision and trustworthy public hash record without obtaining or redistributing ROM images.

Targets to enumerate:

- No-Intro / DAT-o-MATIC metadata and revision records
- GameTDB or equivalent catalog identifiers where independently useful
- release databases with product/cart codes
- cartridge/box/manual scans with identifiable revision markings
- hash lists published by preservation projects

State: **Enumerating**. Public hash claims are not promoted to project `Observed`/`Matched` status merely because they appear in a catalog.

### 13. Remaining mandatory source classes

The following classes remain open until separately enumerated and linked:

- official strategy guides and publisher-authorized guide material
- physical manual/box/cart scans by region/revision
- magazines and contemporary press carrying official screenshots/interviews
- developer interviews and Game Freak/Nintendo staff statements
- soundtrack releases, track lists and audio documentation
- localization-specific screenshots/video captures
- bug/glitch reproduction research and revision-fix evidence
- emulator test results only when separated from real-hardware behavior
- academic/technical papers if any directly analyze Gen V formats or networking
- historical fan tools no longer hosted at their original locations

## Census rule

**Do not move to “all public sources surveyed” until every category above has either been enumerated or explicitly documented as unavailable/blocked with the search path recorded.**

Finding one authoritative source does not close a category. Conflicting sources are retained as conflicts. Missing information remains `unknown`/`TBD`.
